# BLOCKS — ブロックパズル

**[ブラウザで遊ぶ（GitHub Pages）](https://president-code-ai.github.io/Pazzle-load/)**

スマートフォンでは、次のQRコードをカメラで読み取って開けます。

![ゲームのPages URLを開くQRコード](assets/Pazzle-load-QR.png)

[QRコードのPNG](assets/Pazzle-load-QR.png) / [印刷用SVG](assets/Pazzle-load-QR.svg)

**`index.html` をダブルクリックしてEdgeなどで開くと遊べます。**
インストール・サーバー・インターネット接続は不要です。`index.html`、`style.css`、`stages.js`、`core.js`、`app.js` の5ファイルを同じフォルダーに置いてください。

1990年にビック東海から発売されたゲームボーイ用『冒険！パズルロード』を参考に、全42面の枠とブロックをブラウザで遊べる形にしました。非公式の独自実装です。原作のROM・画像・音楽は使用していません。

## 遊び方

ブロックを回転・反転させ、枠をすき間なく埋めたらクリアです。解答はお手本と違っていてもかまいません。使わないブロックがある面もあります。最後の42面には4マスの正方形が登場します。

1. 一覧からブロックを選びます。スマホの一覧は横にスワイプできます。
2. 回転・左右反転・上下反転で向きを変えます。
3. スマホでは盤面をタップ・指で移動し、影の位置を合わせます。矢印ボタンで1マスずつ微調整し、**「置く」で確定**します。指を離すだけでは置かれません。斜線の位置には置けず、確定ボタンも無効になります。影の左上がカーソルの位置です。

幅の広いPC画面では、ブロックを選んで盤面をマウスでクリックすると直接置けます。幅760px以下の画面は、マウスでもプレビューしてから「置く」で確定します。キーボード操作も使えます。

配置済みのブロックも盤面・一覧から選び直せます。「取消」で元の位置に戻り、「枠から外す」で一覧へ戻せます。「1手戻す」や「お手本」も利用できます。横向きのスマホでは盤面の隣に操作を配置します。ゲーム中の大きな原作タイトル表記は削除し、調査元の説明は「調査・再現について」に残しています。

| キー | 操作 |
| --- | --- |
| 方向キー | カーソル移動 |
| A / 盤面にフォーカスしてEnter・Space | 置く・拾う |
| B / R | 左回りに90度回転 |
| H / V | 左右反転 / 上下反転 |
| 1〜9 | 一覧の1〜9番目を選択 |
| Tab → Enter | ボタンを選ぶ。10個目以降のブロックにも対応 |
| Esc | 選択を元に戻す・開いている説明を閉じる |
| Delete / Backspace | 選択した配置済みブロックを外す |
| Z | 1手戻す |

時間制限はありません。説明やお手本の表示中、別タブを見ている間は時計が止まります。

## 続きから遊ぶ

進行・クリア記録はタブを開いている間だけ保持します。**ページを再読み込みしたり閉じたりすると、配置や記録は消えます。** 自動保存はありません。

再開する場合は、各面のパスワードを控え、「パスワードで再開」へ入力してください。最初はパスワード不要、2面は `SHMT`、最終42面は `OOEI` です。原作同様 `ZEAL` は面選択を開きます。本再現版では「島を選ぶ」からも自由に全42面を選べます。

## データと確認結果

- 外部通信・広告・アクセス解析・Cookie・ブラウザへの永続保存は使いません。「調査・再現について」の資料リンクを押した場合は外部サイトを開きます。
- 追加ライブラリやフォントは使用していません。
- 全42面の枠・必要ブロック・パスワードは公開攻略資料と照合しました。ブロックの入手順の一部は解答図からの推定です。
- 原作の島間の移動演出・音楽・タイトル画面・実機操作そのものは再現していません。
- Edge 157で実ブラウザの操作・表示を確認しています。Firefox・Safari・実スマートフォンは未検証です。

調査の根拠と再現範囲は [RESEARCH.md](RESEARCH.md)、実施したテストと制約は [VALIDATION.md](VALIDATION.md) に記載しています。

開発用の検証は既存Node.jsで `node --test tests/core.cjs`。追加パッケージは不要です。`tests/browser.cjs` は既存Edgeを起動する検証専用で、通常の遊び方では使用しません。ブラウザ・OSへの影響について承認された場合だけ `PUZZLE_ROAD_BROWSER_APPROVED=1` を指定して実行します。

## GitHub Pages

公開元は `main` ブランチの `/ (root)`。ルートの `index.html` がゲーム本体なので、PagesのトップURLでゲームが開きます。`.nojekyll` によりそのまま静的ファイルとして公開します。追加のビルド・パッケージ導入は不要です。

QRは既存の自作エンコーダー `tools/generate-qr.cjs` でローカル生成しました。外部QRサービスや追跡用の短縮URLは使っていません。出力先は `assets/` で、PNGからのURL復元、PNGのCRC、誤り訂正符号を生成時に検証します。既存ファイルを無断で上書きしないため、再生成時は明示的に出力を整理してから実行してください。
